Types & Components of Computer Systems

Hardware, the CPU, signals, software types, memory, storage overview, OS interfaces, computer categories and emerging tech.

1.1 Hardware

Internal hardware lives inside the system unit:

CPUCentral Processing Unit — the primary processor that interprets and executes system instructions.
MotherboardThe main printed circuit board that connects every internal component so they can communicate.
RAMRandom Access Memory — volatile primary memory used for temporary data storage while processing.
HDD / SSDSecondary storage devices used for persistent, non-volatile data storage.
NICNetwork Interface Card — wired (Ethernet) or wireless (WNIC) hardware that connects a device to a network.
GPUGraphics Processing Unit — a specialised processor for rendering graphics, 3D images and video.

External hardware (peripherals): Input devices (mouse, keyboard, microphone, scanner, webcam) enter data; output devices (speaker, monitor, printer, projector, actuator) present processed data to the user.

1.2 CPU Components

  • ALU (Arithmetic Logic Unit) — performs arithmetic calculations (add, subtract) and logical decisions (AND, OR, comparisons).
  • CU (Control Unit) — coordinates and manages the flow of data and the execution of instructions across the processor and the system.

1.3 Signals & Data Conversion

Computers only understand digital data (0s and 1s). Real-world data from sensors or microphones is analogue, so it must be converted.

1.4 Software Types

Application software

Provides the services a user needs for a specific task: word processing, spreadsheets, database management (DBMS), control & measurement software, apps/applets, video editing, graphics editing (bitmap vs vector), audio editing, and CAD (Computer-Aided Design) for precise 2D/3D models and cost estimation.

System software

Manages the hardware and provides the platform application software runs on:

CompilerTranslates high-level code into machine code all at once, producing an independent executable file.
LinkerLinks separate object code files and compiled libraries into one executable program.
Device driverLets the OS communicate with and control a specific hardware device, e.g. a printer or graphics card.
Operating SystemManages hardware resources (RAM, CPU cycles) and provides a user interface, e.g. Windows, macOS, iOS.
UtilitiesSupport software that maintains, optimises and protects the system — antivirus, disk defragmenters, backup tools.

1.5 Primary Memory

  • RAM — temporary, volatile memory (loses data when powered off); holds the running apps, OS components and data in active use.
  • ROM — permanent, non-volatile memory (keeps data with no power); stores the BIOS and the bootstrap loader (start-up instructions).

1.6 Storage Technologies Overview

  • Magnetic — magnetised platters or tape (HDD, magnetic tape).
  • Solid state — flash memory chips (NAND), no moving parts (SSD, USB, SD cards).
  • Optical — a laser reads/writes pits and lands on a reflective disc (CD, DVD, Blu-ray).
  • Cloud — files stored on remote internet servers across public, private or hybrid environments.

1.7 Operating System User Interfaces learn advantages AND disadvantages

1.8 Computer Categories & Processing

Categories: Desktop/All-in-One, Mobile computers (laptop, tablet, smartphone, smartwatch), Embedded computer (built into appliances like a washing machine), Server, Mainframe (bulk financial transactions), Supercomputer (scientific calculations), Minicomputer, Microcomputer, AI computers, and Quantum computers.

Binary vs Quantum: traditional microcomputers process bits as either 0 or 1. Quantum computers use qubits, which use superposition to exist as 0, 1, or both at once — enabling far more complex calculations.

1.9 Emerging Technologies

  • Artificial Intelligence (AI) — systems that simulate human intelligence: natural language processing (translation, voice assistants), smartphone facial recognition and predictive text, and autonomous vehicles that navigate and react in real time.
  • Immersive tech — Augmented Reality (AR) overlays digital content on the real world (e.g. navigation heads-up display); Virtual Reality (VR) fully immerses the user in a generated 3D world using a headset; Mixed Reality (MR) blends real and virtual objects that interact in real time.

Exam tip

If asked to "describe" a difference (e.g. RAM vs ROM, or CLI vs GUI), always give a point for each side — one mark for RAM being volatile/temporary, another for ROM being non-volatile/permanent. Don't just name them.

Input & Output Devices

Manual input, sensors, direct data entry, cards, barcodes/QR codes, and every output device you need for the exam.

2.1 Manual Input Devices & Sensors

  • Keyboard — fast for skilled typists but slower than direct data entry and prone to typing errors.
  • Numeric keypad — used at ATMs and POS terminals for fast numeric/PIN entry.
  • Pointing devices — mouse, touchpad, tracker ball, joystick, driving wheel; control the on-screen cursor.
  • Scanner — converts paper documents into digital form, often using OCR (Optical Character Recognition) to turn a scanned image of text into editable text.
  • Digital camera and microphone — capture images and analogue sound respectively.

Key term, in full

Sensor — a device that measures a physical property (temperature, pressure, light, sound, moisture, pH) in the real world. The processing loop is: Sensor (analogue) → ADC → microprocessor compares the reading with preset parameters → DAC → actuator/motor/alarm reacts.

2.2 Direct Data Entry, Cards & Barcodes

OMROptical Mark Recognition — reads pre-printed marks in fixed positions, e.g. multiple-choice exam sheets or lottery tickets.
OCROptical Character Recognition — scans printed or handwritten text and converts it into editable digital text.
MICRMagnetic Ink Character Recognition — reads the special magnetic ink characters at the bottom of bank cheques for automated processing.
RFID / NFCRadio Frequency Identification / Near Field Communication — contactless tracking and payment technology.
Barcode (1D) vs QR Code (2D)
FeatureBarcode (1D)QR Code (2D)
Data directionHorizontal onlyHorizontal and vertical matrix
Storage capacityLow — numeric codes onlyHigh — URLs, text, media, contact details
Scanning methodLaser scanner, needs direct alignmentSmartphone camera or scanner, any angle

2.3 Output Devices, Displays, Printers & Projectors

Displays: CRT (heavy, legacy, hot); LCD (flat panel, CCFL backlight); LED (LCD backlit by LEDs — brighter, thinner, more efficient); OLED (self-emissive pixels, true blacks, flexible); IPS (wide viewing angles, accurate colour).

Printers: Laser (fast, dry toner, crisp text for offices); Inkjet (liquid ink droplets, great for photos, cheaper but slower and can smudge when wet); 3D printer (builds solid objects layer-by-layer from a CAD model); Dot-matrix (impact printer, noisy, used for continuous or multi-part carbon-copy paper).

3D printing in medicine

3D printing starts with a CAD model. Applications include custom prosthetic limbs (faster and cheaper than traditional manufacturing), bioprinted tissue to repair damaged organs and reduce transplant waiting lists, and biodegradable artificial blood vessels used in surgery.

Projectors: DLP uses tiny micro-mirrors for high contrast and portability; LCD projectors use three glass panels (red, green, blue) for bright, colour-accurate images.

Storage Devices & Media

Magnetic, solid-state and optical backing storage, plus cloud storage vs cloud computing.

3.1 Magnetic Backing Storage

HDD (Hard Disk Drive) — spinning magnetised platters, a read-write head and an actuator arm. Speed is measured in RPM; rotational latency is the delay while the correct sector rotates under the head. Advantage: large capacity at low cost per GB. Disadvantage: moving parts are easily damaged by shocks or drops.

Other magnetic media: portable HDD (USB, for large backups), magnetic tape (low-cost, high-capacity, sequential-access — good for long-term archiving), and the legacy floppy disk.

3.2 Solid-State Backing Storage

Uses non-volatile NAND flash memory chips with zero moving parts: SSD (fast, durable), USB flash drive (portable, plug-and-play), and SD/XD/CFast memory cards used in cameras, phones and tablets.

3.3 Optical Backing Storage

A laser burns and reads microscopic pits and lands on a spiral track on a reflective disc.

  • CD — about 700 MB.
  • DVD — about 4.7 GB, red laser; dual-layer DVDs have two reflective layers.
  • Blu-ray — 25–50 GB, short-wavelength blue laser (405 nm) for tighter pit packing.

Disc formats: -R (recordable once), -RW (rewritable), -ROM (read-only), DVD-RAM (simultaneous read/write, sector-based).

3.4 Cloud Storage vs Cloud Computing

Don't mix these up

Cloud storage is like a virtual remote hard drive — a place where your files simply sit. Cloud computing is like a virtual computer (CPU + RAM + programs) that actively runs processing tasks and applications over the internet, without using your local hardware.

  • Public cloud — infrastructure owned by a third-party provider, open to public clients.
  • Private cloud — dedicated infrastructure behind one company's own firewall.
  • Hybrid cloud — combines public and private to balance security and cost.

Networks & the Effects of Using Them

Network hardware, addressing, network types, security & access control, anti-malware, and conferencing.

4.1 Core Concepts

Network — two or more devices connected to share data, resources and communication. Internet — a global WAN connecting millions of devices. World Wide Web — the collection of multimedia web pages hosted on web servers, following W3C standards.

4.2 Network Hardware — learn what each device does

NICHardware (card or chip) that connects a device to a network; carries a unique factory-set MAC address. Wired (Ethernet) or wireless (WNIC).
HubNon-intelligent — broadcasts every packet to all connected ports, causing unnecessary traffic and weaker security.
SwitchReads the destination MAC address and forwards data only to the intended port — reduces traffic and improves security vs a hub.
RouterConnects two or more different networks (e.g. home LAN to the internet); reads IP addresses to choose the best route, and often assigns IPs via DHCP.
BridgeConnects two segments of the same LAN using the same protocol; filters traffic by MAC address to reduce congestion.
GatewayConnects two networks that use different protocols, translating data so they can communicate.
WAPWireless Access Point — converts wired signals into Wi-Fi so wireless devices can join a wired network.
ModemModulates/demodulates signals between the analogue phone/cable line and digital computer data.

4.3 Network Addressing

IP address — the logical location of a device on a network. IPv4 uses 32 bits, written in denary (e.g. 192.168.1.1). IPv6 uses 128 bits, written in hexadecimal, to solve the shortage of IPv4 addresses.

MAC address — uniquely identifies hardware, set at the factory. Built from 48 bits (6 hex pairs): the first 24 bits are the manufacturer ID, the last 24 bits are the device's serial number.

4.4 Types of Networks

  • WAN — covers a large area (cities, countries); fibre-optic, leased lines, satellites.
  • WLAN — a wireless LAN, usually Wi-Fi over 2.4 GHz / 5.0 GHz radio waves.
  • LAN — a small area (home, school, office), using switches or hubs.
  • PAN — a very small personal range (~10 m), commonly Bluetooth.

4.5 Security & Access Control

Biometrics (fingerprint, face, iris), physical tokens (smart cards, security keys, USB dongles), electronic tokens / OTP (one-time passcode via SMS, email or an app), and strong passwords (mixing upper/lowercase, numbers and symbols).

4.6 Anti-Malware Software

Anti-virus — scans files against malware signature databases, quarantines suspicious files, and cleans infections. Firewall — hardware or software that monitors incoming/outgoing traffic against security rules.

4.7 Electronic Conferencing

Hardware needed: microphone (audio in), webcam (video in), speakers/headphones (audio out). Common platforms: Zoom, Google Meet, Microsoft Teams.

Common mix-up

A hub broadcasts to everyone (dumb device); a switch sends only to the right device (smart device). A router connects different networks together and routes by IP address; a bridge connects two parts of the same network and filters by MAC address.

The Effects of Using IT

Microprocessor-controlled devices, health problems and their fixes, and physical safety hazards.

5.1 Microprocessor-Controlled Devices

Positive impacts: saves time through automation, increases leisure time, allows remote control via apps, high convenience. Negative impacts: encourages a sedentary lifestyle, creates dependency on technology, and can cause a loss of manual skills (deskilling).

Examples: smart fridges that track and reorder food, smart heating that learns routines to save energy, automated smart security systems, and self-driving cars/drones that use sensors and microprocessors for safety and efficiency.

5.2 Health Problems & How to Fix Them

Health risks of ICT use
ProblemCauseFix
RSI (Repetitive Strain Injury)Repetitive typing or clickingErgonomic keyboard/mouse, wrist rests, regular breaks
Eye strain / headachesScreen glare, flicker, staring too longAnti-glare screens, the 20-20-20 rule, regular eye tests, good lighting
Back / neck achePoor posture, non-adjustable chairsAdjustable ergonomic chair with lumbar support, footrest, monitor at eye level

Exam tip — the 20-20-20 rule

Every 20 minutes, look at something 20 feet away for 20 seconds. It's a favourite exact-detail answer CIE examiners look for when asking how to prevent eye strain.

5.3 Physical Safety Hazards

  • Trailing wires (tripping hazard) — use cable ducts, route cables under desks, use wireless where possible.
  • Overloaded sockets (fire hazard) — avoid chaining extension blocks, install more wall sockets, keep tested fire extinguishers available.
  • Heavy equipment (fall hazard) — use strong, stable desks, and keep devices away from desk edges.

ICT Applications

Real-world systems: modelling, control, schools, booking, banking, medicine, expert systems, retail, recognition and satellites.

6.1 Communication & E-Publications

Digital tools: email, video conferencing, VoIP, blogs, vlogs, wikis, social networks. E-publications (e-books, digital magazines, e-newsletters, PDFs) use responsive design, embedded multimedia, hyperlink navigation and screen-friendly sans-serif type. Advantages: cheap, portable, instantly updated. Disadvantages: needs a powered device, causes screen fatigue, risk of piracy, and a digital divide for those without access or skills.

6.2 Modelling Applications

Computer models simulate real systems safely and cheaply: financial forecasting, climate simulation, flight simulators (pilot training with no real risk), and weather forecasting.

6.3 Computer-Controlled Systems

Examples: automated greenhouses, central heating, traffic lights, chemical process plants.

6.4–6.6 Schools, Booking & Banking Systems

  • School management — biometric/RFID attendance registration, performance tracking, and automated timetabling that avoids clashes.
  • Booking systems — must process in real time to prevent double-booking: select seat → database temporarily locks it → payment confirmed → status updated to "booked".
  • Banking — ATMs (PIN → verify → dispense cash → update balance), EFT (direct transfer between accounts), online banking (secured by encryption and TANs), and clearing (checking transactions between banks).

6.7–6.8 Medicine & Expert Systems

Medicine: centralised patient records for instant history retrieval, sensor-based patient monitoring with automatic alarms, and high-tech imaging (MRI/CT) plus robotic surgery.

Expert systems emulate a human expert's decision-making:

User interfaceWhere the user types queries and views advice.
Inference engineThe "brain" that applies logical rules to inputs to reach conclusions.
Knowledge baseThe repository of facts collected from human experts.
Rules baseThe set of IF–THEN rules the inference engine applies.

Used for medical diagnosis, mineral prospecting, chess strategy and tax advice.

6.9–6.11 Retail, Recognition & Satellite Systems

  • POS — scans barcode → looks up price → prints itemised bill → updates stock. EFTPOS links POS directly to the bank for instant card authorisation.
  • ANPR — camera captures the plate → OCR converts the image to text → checked against a database.
  • GPS — satellites broadcast time/location, needing signals from at least 3–4 satellites. GIS analyses layered geographic data. Remote sensing maps weather and deforestation from orbit.

7.1 Analysis

Research methods for the current system
MethodProsCons
ObservationReveals actual operational realityWorkers may change behaviour when watched (Hawthorne effect)
InterviewsDetailed, qualitative insightTime-consuming and costly
QuestionnairesFast, cheap, reaches many usersLow response rate, no follow-up questions
Document examinationShows the exact data requirementsRigid — misses human/operational issues

All findings feed into a Requirements Specification — a document listing the hardware, software, user needs and constraints for the new system.

7.2 Design

Designers plan Data Flow Diagrams (DFDs), data capture forms, screen layouts, report layouts, validation/verification rules, data structures (file organisation, field names/types/lengths) and hardware/software specifications.

7.3 Development & Testing — the 4 data types

Normal dataValid data inside the expected range, e.g. entering 55 for a mark out of 100.
Abnormal / erroneous dataInvalid data that validation should reject, e.g. "abc" or 150 for a mark.
Extreme dataValid data right at the boundary, e.g. 0 or 100 for a mark.
Live dataReal data from the old system run through the new one to compare accuracy.

7.4 Implementation — Changeover Methods

Changeover methods compared
MethodHow it worksAdvantageDisadvantage
DirectOld system stops; new one starts immediatelyImmediate benefit, lowest costHigh risk — no fallback if it fails
ParallelOld and new run side-by-side for a periodSafe — old system is a full backupExpensive, duplicate data entry
PilotNew system tested in one branch firstFailure only affects that branchDelays full rollout
PhasedIntroduced module by moduleErrors stay isolated to one moduleVery slow; integration issues between modules

7.5 Documentation

User documentation — for end-users: installation, requirements, saving/printing, error handling, FAQs. Technical documentation — for programmers/analysts: source code, algorithms, flowcharts, field definitions, validation rules.

7.6 Evaluation

Compare the finished system against the original Requirements Specification, identify limitations and future improvements, gather user feedback, and compare performance against the old system.

Exam tip

If a scenario asks you to choose a changeover method, always justify with risk vs cost: parallel running is safest but most expensive; direct changeover is cheapest but riskiest.

Safety & Security

Physical safety, the Data Protection Act, e-safety, and — in full detail — every major security threat and how systems repair and defend against them.

8.1 Physical Security & Safety Hazards

Physical security methods: key/electronic locks, CCTV, biometric access control, security guards, and hardware anchoring (cable locks, floor/desk mounts).

Physical safety hazards and prevention
RiskCausePrevention
ElectrocutionSpilt liquids, exposed/damaged wires, unsafe socketsBan drinks in computer rooms; use circuit breakers (RCBs); inspect wiring and insulation
Fire hazardOverloaded sockets, blocked vents/dust, short circuitsMore sockets, no daisy-chained extensions; clear vents; ventilate the room; keep tested extinguishers ready
Tripping hazardTrailing wires, damaged flooringCable ducts, route cables under desks, use wireless where possible
Personal injuryHeavy equipment falling from unstable desksStrong, sturdy desks; keep equipment away from desk edges

8.2 Data Protection & E-Safety

Data Protection Act — 4 key rules:

  1. Data must be accurate and up to date.
  2. Data must not be kept longer than necessary.
  3. Data must be fairly and lawfully processed.
  4. Data must be kept secure against unauthorised processing, loss or damage.

Personal data identifies a living individual (name, address, email, date of birth). Sensitive personal data needs extra protection (political views, religion, criminal record, biometric data).

E-safety guidelines: never share personal details online; use strict privacy settings; block/report cyberbullies; only add people you actually know; check for the padlock/https:// on websites; be wary of email attachments and phishing links.

8.3 Security of Data — threats, and how each is repaired/prevented

This is the section most exam questions expect in full detail: name the threat, explain how it works, and state the specific prevention or repair method.

HackingUnauthorised access to a system. Repaired/prevented by firewalls, strong passwords and user access controls.
PhishingFake emails trick users into giving up credentials. Prevented by user training and checking the sender's email domain is genuine.
PharmingMalicious code silently redirects users to a fake website. Prevented by up-to-date anti-malware and checking for HTTPS/the padlock icon.
Smishing / VishingPhishing carried out by SMS text message (smishing) or a phone call (vishing).
MalwareViruses, spyware and ransomware. Prevented by anti-virus software and avoiding unknown links/downloads.
Types of malware — repair and defence starts with knowing which one you have
MalwareHow it behaves
VirusReplicates itself to delete or corrupt files; needs an active host program or infected OS to run.
WormStand-alone; replicates and spreads on its own across networks that have weak security.
Trojan horseMalicious code disguised as legitimate software, which it replaces or embeds itself into.
SpywareSecretly monitors activity and sends data to the attacker, often including keylogging.
AdwareFloods the system with unwanted pop-ups and may redirect the browser to advert sites.
RansomwareEncrypts the victim's files and demands payment for the decryption key — usually delivered via a Trojan.

How anti-virus software repairs an infected file

Anti-virus software works in three stages: it scans files against a database of known malware signatures, quarantines any suspicious file so it cannot run or spread, and then either cleans/repairs the file by removing the malicious code, or deletes it if it cannot be safely repaired. Keeping the signature database updated is essential, because it can only recognise threats it already knows about.

8.3.2 Protection & Authentication Methods

BiometricsUses a unique physical trait — fingerprint, face or iris — to confirm identity.
Digital certificateA public/private cryptographic key pair used to authenticate identity and secure communication.
SSLSecure Sockets Layer — a protocol that encrypts network traffic for safe transmission over the internet.
EncryptionConverts readable plaintext into unreadable ciphertext using a key, to stop unauthorised access in transit or storage.
2FATwo-Factor Authentication — two separate proofs of identity, e.g. a password plus a one-time passcode.

Card fraud: card cloning (copying card details) and shoulder surfing (watching someone type their PIN).

Audiences

Tailoring ICT work to who will actually read, watch or use it — plus copyright and plagiarism.

9.1 Audience Appreciation

  • Age — young children need bright colours, simple vocabulary and large text; adults/professionals need structured, data-driven layouts.
  • Target group — specific interests, language ability and digital literacy level.
  • Context — a formal business presentation needs a different style to a casual blog or social post.

When writing a presentation, consider: the language used, how much multimedia to include, the length, how much audience participation is invited, and whether practical examples are used to illustrate points.

Audience characteristics to plan for: age range, income level, specific interests, disabilities (visual/auditory), and the different expectations of children, adults and older people.

9.2 Copyright & Plagiarism

CopyrightProtects original creative work — music, films, articles, books — from being copied without permission.
LicenceLegal permission to install and run a piece of software.
PiracyUnauthorised copying, distribution or use of copyrighted software.
PlagiarismCopying someone else's work, ideas or text and presenting it as your own without acknowledgement.

Product keys and holograms are used as security controls to verify that a software installation is genuine.

Quick recap — Chapter 9

  • List 3 factors to consider about your audience before designing a document
  • Explain the difference between copyright and plagiarism
  • Explain what a software licence gives you permission to do

Communication

Email, the internet vs the World Wide Web, web platforms, protocols, and staying safe online.

10.1 Communicating by Email

Internet is a global public network of networks; an intranet is a private internal network for one organisation only (e.g. a school portal).

Email structure: To, CC (Carbon Copy), BCC (Blind Carbon Copy — hides recipients from each other), Subject, message body, attachments.

Netiquette: use appropriate language, never type in ALL CAPS (it reads as shouting), keep messages concise, and respect other people's privacy.

10.2 Effective Use of the Internet

Internet vs World Wide Web
InternetWorld Wide Web (WWW)
The global network of interconnected networks and devicesA collection of multimedia web pages hosted on websites
Uses TCP/IPUses HTTP/HTTPS to transmit HTML documents
Carries email, chat, FTP file transferUses URLs to locate web pages
The underlying physical network infrastructureAccessed through web browser software

Web platforms: Blogs (personal online journals), Wikis (collaborative, editable pages), Social networking sites (profiles and shared media), Forums (threaded discussion boards).

Navigating the internet: an ISP provides your connection; a web browser lets you view pages; a search engine searches an index of websites for your keywords. Use quotation marks for an exact phrase and AND/OR/NOT as logical search operators.

Evaluating whether a website is reliable

  • Check the domain — .gov and .edu are generally more authoritative
  • Verify the author's credentials
  • Watch for spelling and grammar errors
  • Check when the page was last updated
  • Cross-reference the facts against other trusted sources

URL structure: protocol://website address/path/filename

Communication Protocols

IPInternet Protocol — directs and routes data packets across networks.
POPPost Office Protocol — used by email clients to retrieve email from a mail server.
FTPFile Transfer Protocol — transfers files between computers over a network.
HTTPHypertext Transfer Protocol — transmits web page data across the internet.
VOIPVoice over Internet Protocol — carries voice/audio calls over an IP network.
SSLSecure Sockets Layer — encrypts data sent over the internet.

Internet risks to remember

Malware, phishing scams, unauthorised network access, pharming and cyberbullying are the risks CIE most often asks you to identify and suggest a prevention for — link each one back to the specific defence covered in Chapter 8.
